# Arabic Text Support – Installation

## Installation

1. Open the Terminal.
2. Run the following command:

```bash
pip install arabic-reshaper python-bidi
```

## Required Libraries

- **arabic-reshaper:** Fixes Arabic letter shaping and connects letters correctly.
- **python-bidi:** Handles Arabic right-to-left (RTL) text direction.

## Note

Make sure to install these libraries before running the project.
